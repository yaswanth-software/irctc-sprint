# IRCTC Sprint

This repository contains a UX and product audit of the IRCTC platform as part of the IRCTC Design Sprint assignment.

---

# Objective

The objective of this project is to:

- Explore the live IRCTC platform
- Identify major usability and booking flow issues
- Document real user pain points
- Analyze where and why failures occur
- Prepare solution proposals for Part B

Part A — Problem Discovery

Part A focuses on documenting 6 major problems found on the IRCTC platform.

Given Problems
Tatkal Booking Crashes at 10:00 AM
Search Filters Do Not Work Reliably
Seat Selection Resets During Booking
Self-Discovered Problems
Passenger Details Form Is Overloaded and Confusing
Mobile Website Navigation Breaks Frequently
Cancellation and Refund Information Is Difficult to Understand
Problem Documentation Includes

For every problem:

What is broken
Affected users
Frequency of occurrence
Step-by-step user flow
Exact failure point
Screenshots or observations
